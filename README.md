# Plants Vs Zombies Mod

### This mod adds "plants" to quake 4 which you can use to defend yourself from waves of zombies

Features:
-Custom turret plants with different attacks

-Money system for buying and placing plants

Install pak 001 into a mod folder as well as the DLL placed in game001.pk4 (also in the mod folder). Load Quake4 and load the mod folder, then begin playing
